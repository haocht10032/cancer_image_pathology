# Rights and licensing review

No LICENSE file is supplied because the authors have not confirmed the project's
license and ownership approvals. The published `v1.0.0` Zenodo record
(https://doi.org/10.5281/zenodo.23105039) currently lists CC BY 4.0; the author has
indicated that this archive license needs confirmation. No repository LICENSE
was added or Zenodo license changed during the DOI documentation update.
Confirm the intended archive and repository licenses with coauthors/institutions and
preserve all applicable third-party notices. A code license does not automatically
license datasets, pretrained models, derived weights or manuscript materials.

Third-party dependencies include PyTorch/torchvision, timm, Hugging Face Hub,
NumPy, SciPy, pandas, scikit-learn, Pillow, matplotlib/seaborn, Jupyter, and R
reporting packages. Their code is not vendored here. DINO/DINOv2, UNI and
MaskCut/CutLER must retain their upstream attribution and applicable terms.
Review any adapted algorithm implementations before asserting original ownership.

The source project included copies of upstream `maskcut/` and `uni/`; neither is
bundled. Restricted weights, dataset images, professor feedback, correspondence,
and unapproved manuscript drafts are also excluded. This does not certify all
possible IP/privacy requirements: the authors must approve the public package.
