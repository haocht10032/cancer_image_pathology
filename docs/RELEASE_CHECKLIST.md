# Before publishing

- [ ] Coauthors approve public code, derived outputs and citation metadata.
- [ ] Confirm ownership/license; add an approved LICENSE and upstream notices.
- [ ] Export a complete dependency lock from the original online environment.
- [ ] Review sanitized paths, clean notebooks, numeric exports and package audit.
- [ ] Test a clean-machine install and at least the proof workflow with authorized assets.
- [ ] Sanitize/approve the separate large-output archive; publish its manifest/DOI.
- [ ] Inspect the destination repository's existing contents before committing.
- [ ] Commit the reviewed package, then create an explicit tagged release.
- [ ] Record the tag/commit/archive DOI in CITATION.cff, README and manuscript.

No repository was cloned, initialized, pushed or modified remotely during package
preparation. This folder is a local review candidate, not proof of a public release.
